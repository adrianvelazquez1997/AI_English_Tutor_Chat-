# 🧠 AI English Tutor

Aplicación de Inteligencia Artificial para aprender inglés mediante un chatbot que:

- Corrige errores gramaticales  
- Explica los errores de forma clara  
- Mantiene una conversación natural  

## 🎯 Objetivo

Construir un **asistente inteligente de aprendizaje de inglés** basado en LLMs, con una arquitectura preparada para evolucionar hacia un sistema **multimodal (texto + voz + imagen)**.

---

## 🧩 Funcionalidades actuales

💬 Chat conversacional en inglés  
✏️ Corrección automática de frases  
📖 Explicación de errores  


## 🔮 Próximas funcionalidades

- 🔊 Text-to-Speech (voz del tutor)  
- 🖼️ Generación de imágenes para reforzar conceptos  
- 📚 RAG completo con PDFs (cheat sheets y libros)  
- 🎯 Mejora de prompts y evaluación de respuestas
